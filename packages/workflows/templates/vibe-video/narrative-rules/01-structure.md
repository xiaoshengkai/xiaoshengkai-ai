# 结构纪律：叙事骨架

> 排版规则管"好看"，本文档管"观众看不完吗、看懂吗"。数据差距主要来自叙事，不来自画面精度。

## 1. 选题四问（任何一项弱就换题）

| 项 | 自问 |
|---|---|
| 钩子 | 观众是不是正处在这个处境里？（考试、社交、消费、身体、情绪） |
| 故事线 | 有没有真实的年份、人物、论文或事件，能串成一段历程？ |
| 可演示 | 有没有一个机制能用画面真演出来，并贯穿全片？ |
| 反转 | 是不是"你以为 A，其实 B"，并且能叠两到三层？ |

只讲知识、与观众生活无关的题不做。

## 2. 三种骨架（按内容选一）

| 骨架 | 走法 | 适合 |
|---|---|---|
| A 历史接力 | 问题 → 一站站走（人+事+当场演示）→ 回到今天的你 | 一个概念的发展史 |
| B 反常+机制 | 反常现象 → 真实事件 → 命名 → 机制逐步演示 → 多层反转 → 回到开头 | 统计现象、心理学实验、反直觉事实 |
| C 隐喻+重新解读 | 日常画面排比 → 概念 → 机制 → 套到观众身上 → 重新解读 | 概念类比人生 |

骨架 A 必须有一条悬着的线：早点抛出一个错误答案或未解的问题，隔几幕再回来解掉。没有这条线，编年体就是流水账。

## 3. 标准时间轴（按场景数等比缩放，以 12 幕为基准）

| 位置 | 内容 | 硬性要求 |
|---|---|---|
| 第 1-2 幕 | 钩子 | 第 1 秒就有画面+旁白；反常识断言 / "你以为……其实……" / 让人对号入座，三选一 |
| 第 2-3 幕 | 主题卡/转折点 | 观众先"遇到"概念，再点题（如果是标题式开头则反过来） |
| 第 3-6 幕 | 真实事件/实验 | 年份、人物、数据；**埋下悬念**；中间插一次"你猜" |
| 第 6-10 幕 | 机制演示 | 一个模型从头用到尾，数字实时变化；叠 2-3 层反转 |
| 第 10-11 幕 | 解开悬念 | "现在，回到开头那个问题——" |
| 末 2 幕 | 落到观众 + 回扣 | 分步建议（每步一个动作）或重新解读；结尾呼应开头；不说教 |

## 4. 十条叙事定律

1. **片名/主题不第一个出。** 先用两三幕演一个具体的小东西，让观众先"遇到"概念。
2. **至少埋一个悬念，过半才解。** 悬念要具体到"一个数或一个答案"，不是模糊的"为什么"。
3. **反转 2-3 层**，用"更离谱的是""还有一个反直觉的细节"引出；每层反转比前层更贴观众自身。
4. **画面上永远有一个在变的读数**：计数器、年份戳、进度、"第 N 步"。它既是进度条也是证据。
5. **每个结论都有实物佐证**：年份、人名、数据来源。数字一律具体，禁止"很多次""差不多"。
6. **中段一定转到"你"**：出现在全片 40-45% 处，"你猜……""这句话是不是很耳熟？"
7. **一个模型从头用到尾**：同一组道具、同一个图形反复出现、持续变化。观众会记住它、期待它。
8. **结尾替观众开脱或重新解读，不说教**："你不是不够好，是策略本来就有上限。"末句常是开头那句的变体。
9. **场景不换、旁白推进**：不是一句旁白配一张新图；同一场景撑 2-3 句，每句只改一处。
10. **留呼吸口**：每 6-8 幕有一幕让机制自己跑（旁白闭嘴或极简），这是"真在算"的证明时间。

## 5. 反转的正确叠法

- 第一层给"惊讶"（结果反直觉），第二层给"机制"（为什么会这样），第三层给"照进自己"（你的生活里它一直在发生）。
- 每层反转前先给足铺垫（观众自己得出过一次错误答案），反转才有力。
- 最大的一次揭晓，配全片最强的一次画面强调（脉冲/擦除转场/定格），一条片只用一次。

## 6. 常驻读数设计

把全片核心概念做成一个**仪器**（表盘/进度条/水位），每个新例子出现就拿它量一次，读数跟着变。
检验：能不能说出"那个常驻读数量过了哪几样东西"？说不出，说明核心概念还没被具象化。
