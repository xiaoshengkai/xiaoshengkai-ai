# 讲解设计：让画面开口讲课

> 本文档解决比"好看"更根本的问题：**观众看不看得懂**。一幕画面如果放到任何其他视频里都能用，它就是配图，不是讲解——观众只记得"挺炫的"，说不出内容。

## 1. 先给概念找形象，再写句子

**画不出来的句子，改句子，不硬配抽象动画。**

拿到概念清单后，对每一个概念按顺序自问，前一级有答案就停：

1. **它本身是看得见的东西吗？**（骰子、红绿灯、蜗牛、银行卡）→ 直接画它本身，一眼认得出。
2. **它是一个过程或方法吗？**（二分查找、复利）→ 找一个规模小到每步都能画出来的具体例子，现场从头跑到尾。
3. **它是一个数量或程度吗？**（概率、拥挤度）→ 发明一把全片通用的"尺子"（表盘/进度条），用它量三样不同的东西。
4. **它是观众脑子里的感受吗？**（直觉、错觉）→ 设计一个五秒小情境，让这个感受当场发生在观众身上。
5. **它是一条规律吗？**（越多越……）→ 先画两三个具体例子，再收进同一张坐标系，轴用大白话命名。
6. **都不是**（判断、总结）→ 不画。停住上一幕，或者只上字。

## 2. 每一幕的三道自检

| 自检 | 合格答案 | 不合格答案 |
|---|---|---|
| 屏上这是什么？ | 一个日常的词："一摞硬币""一格日历" | "一些点""一个抽象图形" |
| 它在干什么？ | 一个动词，且就是旁白里那个动词 | "在展示""在流动" |
| 观众明白了什么？ | 一句能与上一幕区分开的话 | "感受到了氛围" |

遮住旁白只看画面，三道题还答得出来吗？答不出，说明画面在依赖文字补课。

## 3. 六种呈现动作（每句旁白标一种）

1. **让观众动手**：画面摆一个现象，观众先自己起反应，旁白晚半拍说出他刚想的事。适合开场和"你以为……"的位置。
2. **照句子演**：句子里的名词，画面里就有；句子里的动词，画面里真的发生。画面不比句子多说一个字。
3. **小题现场跑**：拿一个最小的具体算例，把机制一步步执行完，屏上挂着状态和计数。旁白可以闭嘴让过程说话。
4. **同版式对照**：两样东西放进完全相同的版式，只留一处不同，观众一眼看出"区别就在这"。适合一切"甲比乙"。
5. **收进一张图**：把前面出过场的东西摆进一张坐标图，轴用大白话，重点落在图上一块区域。一条片用两三次，排在例子之后。
6. **停住亮字**：规则卡、引文卡、命名大字，或什么都不加把上一幕定住。这是"不画"的合法形式。

贯穿动作：**回场**（前面的道具、尺子后面再出现，接住新结论）和**合体**（把核心比喻和观众的生活物件放进同一画面）。

## 4. 哪些句子不配新画面

大约**每五句里有一句**停住或只上字：

| 这句在干什么 | 处理 |
|---|---|
| 提问 | 停住上一幕，或只留一个问号 |
| 命名、下定义 | 停住亮字，前面的道具围拢过来 |
| 引用原话 | 引文卡：原话 + 出处 |
| 交代年份人物 | 一行小字贴在已有画面上，不为此换场 |
| 总结"为什么会这样" | 收进一张图（用前面出现过的东西摆） |
| 过渡句 | 不画，让下一幕自己进场 |

## 5. 一个比喻用到底

全片只定**一个**核心比喻，它必须是开场就能画出来的具体东西。之后每个新概念都尽量用它来说。观众即使记不住术语，也能用这个比喻复述整条片。换比喻 = 观众刚建好的心智模型作废，不要中途换。

## 6. 句型 → 演法对照表（分镜写不出画面时查）

| 旁白在说 | 这样演 |
|---|---|
| 一个数量、一个比分 | 让它"长出来"且数得清：进度条逐格亮、数字从 0 滚到位 |
| 甲比乙 | 左右两栏同版式，只留一处不同，各盖结论章 |
| 个别没规律、合起来有规律 | 粒子模拟：成百上千个小东西各自落下，堆出形状 |
| 越来越接近 | 实时折线 + 目标虚线 + 在跳的计数 |
| 有多少种可能 | 画成一棵树或格子表，按结果上色 |
| 一个方法、一个过程 | 现场跑一遍：每步一问一答，角上挂状态 |
| 一个公式、一个定义 | 先有例子，公式最后出；每个符号对得上刚出现过的东西 |
| 谁包含谁 | 套圈图，落一个点标出例外 |
| 一句名言 | 引文卡当主体：原话 + 出处 |
| 某年某人 | 不画脸。年代戳 + 一件那个时代的东西 |
| 给概念命名 | 大字 + 强调色，前面的道具围拢过来 |
| 一条规则 | 印成一张卡片，郑重其事（编号、图标） |
| 该怎么做 | 顶上一排步骤标签逐个点亮，每步一个动作 |
| 语言文字类的例子 | 让字自己演：逐字打出、划掉重写 |
| 回顾 | 前面每幕缩成小图标排成一排，逐个点亮 |
