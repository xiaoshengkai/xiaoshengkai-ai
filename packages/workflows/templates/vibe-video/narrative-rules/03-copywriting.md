# 双语字幕稿规范：写给人读的片子

> 这类片子没有配音，观众是在**读**一条片子。字幕稿不是口播稿删掉语气词——每句话要配得上一个屏上动作，短到一眼读完，眼睛还留有余力看画面。

## 1. 量与节奏

| 项 | 要求 |
|---|---|
| 每句字数 | 中文 ≤ 20 字（一行读完）；一行放不下拆两句，各给一个屏上动作 |
| 停留时长 | 每句 2.5–4.5 秒（系统按字数自动计时：约 5–7 字/秒） |
| 信息密度 | 每句必须含一个新信息（事实/数字/转折/动作）；纯过渡句删掉或并入下一句 |
| 无字幕时间 | 15%–30%（标题卡、机制自己跑的段落）——写分镜时就留出来 |
| 英文行 | 每句都有，意译不逐词，比中文短；专有名词用英文原文 |

## 2. 句式工具箱（钩子句、论点句、末句从这里挑）

1. **前半句给直觉，后半句翻过来。**"摸一次，全凭手气；摸上一万次，比例就露馅了。"
2. **破折号后放答案。**"这就是——大数定律。"
3. **定时提问。**每四到六句一个问句；提问句本身不配新画面。
4. **一句话写一个人。**只写一个让他像活人的细节。
5. **"不是 A，是 B"只留给论点。**全片一到两次。
6. **直接对观众说"你"。**钩子末尾一次，结尾一到两次。
7. **数字精确到能上屏。**"很多次"一律查成具体数字。数字是节奏锚点，进 note 标出处。
8. **末句是片名的回声。**定片名时把末句一起想好。
9. **金句前留半秒空。**前一拍用问句收尾。

## 3. 禁用清单（出现即删）

"今天我们来聊聊""让我们一起看看""接下来""这告诉我们""综上所述""众所周知""值得一提的是"、形容词堆叠、说教句（"我们应该……"→"下次……时，想想……"）。全片是陈述句，主语是具体的人和物。

## 4. 强调纪律

- 一句字幕**最多**强调一个词（中文用「」框出，系统转成高亮）。
- 连续三句至少两句素色。
- 强调给"答案、术语、关键数字"。

## 5. 数字纪律（可信感的来源）

1. **先算，后写。**每个数字先查证或标"示意"，写进 note（屏上小字给出处）。
2. **屏上的计数是真的。**"掷了一万次"的画面里计数器要真数到一万。
3. 模拟类数字 note 一律标"示意"。
4. 拿不准的数字宁可换例子。

## 6. 英文行写法

- 一句大白话意译，比中文短 30–50%。
- 句末用句号；金句可保留标点节奏（"—"）。
- 中文人名/术语第一次出现时，英文行用原名：`雅各布·伯努利 → Jacob Bernoulli`。

## 7. 自查

- 只读中文主句：是一篇通顺的短文吗？
- 每句里的名词，画面里找得到对应的东西吗？
- 按 3 秒一句默读，有没有哪句读不完？
