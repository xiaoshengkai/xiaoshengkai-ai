# 逐拍骨架：双语字幕片（90–150s 基准）

> 每拍 = 一条双语字幕 + 一个屏上动作。拍数 25–40，每拍 2.5–4.5s。章节（chapters）按功能段划分 3–6 个，每章交给一个场景函数。

标记：★ = 强调位（全片 6–8 处）；「」= 该拍强调词（≤1 处）。

## 章节结构（对应 role 分布）

| 章 | role 范围 | 功能 | 写法要点 |
|---|---|---|---|
| 一、钩子 | hook ×2-3 + title ×1 | 处境 + 疑问 + 片名卡 | 前半句切入不解释；title 拍的 zh 写副题问句（片名另放 title 字段） |
| 二、故事 | story ×5-8 | 真实事件 + 埋悬念 | 年份人物具体；note 给出处；末拍★悬念金句不解释 |
| 三、机制 | model ×8-14 | 模型演示 + 多层反转 | 常驻读数跳动；数字进 note 标示意；两层反转各配★金句 |
| 四、揭晓 | reveal ×3-5 | 解开悬念 | 固定句式"现在，回到开头"；★揭晓金句对仗 |
| 五、落点 | landing ×3-5 + outro ×1 | 转到"你" + 回扣 | 末拍是片名回声 |

## 拍级写法公式

| 拍型 | 公式 |
|---|---|
| 处境 | 一个具体时刻，≤16 字，不解释："教室里坐了二十三个人。" |
| 疑问 | "是 A，还是 B？"或"可 X，为什么没 Y？" |
| 事实 | 年份 + 主语 + 数字："二〇二二年，人口首次负增长。"（数字拼读不写阿拉伯？字幕**要写阿拉伯数字**——观众是读不是听） |
| 悬念金句★ | 一句话推翻，不解释，强调词框「」 |
| 机制步 | 一句一个动作，动词即画面动词 |
| 对照 | "甲：数字。乙：数字。"只报结果 |
| 反转引子 | 固定句式："更反直觉的是——" |
| 揭晓金句★ | 两句对仗，末词框「」 |
| 小行动 | "① 场景：建议"，冒号前是强调词 |
| 末拍 | 片名回声 + 重新解读，不说教 |

## 五条硬规矩

1. 中文每拍 ≤ 20 字，读出来像说话。
2. 数字先算/查证再写，出处进 note。
3. 金句前一拍是问句或破折号。
4. 同一画面撑 2-3 拍，每拍只改一处（场景不换、字幕推进）。
5. 每章结尾留一拍无字幕纯画面（机制自己跑/读数跳）。

## 自查三件事

悬念在二章埋、四章解；反转 ≥ 两层；末拍回扣钩子。title 拍在 10–25% 处。强调位 ≤ 8。
