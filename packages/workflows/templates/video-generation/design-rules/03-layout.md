# 布局规范

## 3 种布局语法

- **居中叙事**：标题+副标题+正文垂直堆叠（hook、outro）
- **左对齐故事**：标题左上，正文垂直流（叙事 body）
- **右对齐强调**：标题右上，强调结尾（转折、反转）

场景从这 3 种里**交替选择**，不要连续 3 个场景用同一种布局。

## 9:16 竖屏优先

- **优先纵向堆叠**（flex-direction: column）
- 避免横向布局（横排元素在竖屏看着窄）
- 信息从上到下流动：标题上、副标题中、CTA 下
- 主体在垂直 1/3 或 2/3 处（避免贴边）

## 视觉层级

- 每场景一个"焦点"（用大小/颜色/位置突出）
- 其他元素是配角，不要都抢戏
- 字号差异 ≥ 1.8x（层级清晰）

## 容器约束

- 文字最大宽度 ≤ 90%（避免贴边出血）
- 元素层级 ≤ 5 层（超过 5 层视觉混乱）
- 场景边缘 padding：60px
