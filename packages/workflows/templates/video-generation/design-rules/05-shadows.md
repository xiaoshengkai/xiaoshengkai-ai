# 阴影规范

## 软阴影原则

- 始终用**软阴影**（不硬、不黑）
- 阴影颜色与背景色匹配（不纯黑 #000），用 rgba 调透明度
- 移动端阴影不宜过重（屏幕小，过重显脏）

## 3 级阴影表

| 级别 | 阴影值 | 用途 |
|------|--------|------|
| sm | 0 1px 4px rgba(0,0,0,0.06) | 按钮、小元素 |
| md | 0 2px 8px rgba(0,0,0,0.08) | 卡片、表面 |
| lg | 0 4px 16px rgba(0,0,0,0.12) | 浮层、弹窗 |

## 颜色匹配

- 暖色背景：阴影用暖色调（rgba(200,100,50,0.1)）
- 冷色背景：阴影用冷色调（rgba(50,100,200,0.1)）
- 深色背景：阴影用深色调（rgba(0,0,0,0.2)）
- 白/浅色背景：阴影用灰调（rgba(0,0,0,0.08)）

## 反模式

- ❌ 纯黑阴影（box-shadow: 0 4px 12px #000）
- ❌ 阴影太重（rgba(0,0,0,0.5)）
- ❌ 阴影不匹配背景色（暖色背景 + 冷色阴影）
- ❌ 多个阴影混用（3 级以上）
