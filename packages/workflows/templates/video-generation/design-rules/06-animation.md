# 动画规范

## 时长表

| 场景 | 时长 | 理由 |
|------|------|------|
| 微变化（颜色、透明度） | 50-100ms | 几乎无感 |
| 元素入场（小元素） | 200ms | 短促有力 |
| 元素入场（标题、大元素） | 300-400ms | 视觉冲击 |
| 元素出场 | 150-200ms | 比入场快 |
| 复杂转场 | 300-500ms | 但不要超过 500ms |
| 场景总时长 | 3-6s | 短视频节奏 |
| ❌ 禁止 | > 500ms | 移动端太慢 |

## 缓动表

| 缓动类型 | 曲线 | 用途 |
|----------|------|------|
| Standard | cubic-bezier(0.2, 0, 0, 1) | 90% 场景 |
| Decelerate（入场） | cubic-bezier(0, 0, 0.2, 1) | 元素进入，从快到慢 |
| Accelerate（退场） | cubic-bezier(0.4, 0, 1, 1) | 元素退出，从慢到快 |
| Emphasized | cubic-bezier(0.2, 0, 0, 1) | 强调元素 |
| Spring | 弹性曲线 | 按钮反馈、Hook |
| ❌ 禁止 | linear | 机械感 |

## 转场模式

| 转场 | 时长 | 缓动 | 用途 |
|------|------|------|------|
| 淡入淡出 | 200-300ms | standard | 通用 |
| 上滑入（y: 40→0） | 300ms | decelerate | 文字入场 |
| 下滑入（y: -40→0） | 300ms | decelerate | 数字入场 |
| 缩放入（scale: 0.92→1） | 300ms | emphasized | emoji/图标 |
| 弹性入场 | 400ms | spring | Hook 重点 |
| 错位入场（stagger 50ms） | 各 200ms | standard | 列表 |
| 淡出 | 150-200ms | accelerate | 通用 |
| ❌ 禁止 | 旋转/翻转 | — | 太花哨 |

## stagger 规则

- 多元素依次入场，间隔 0.03-0.1s
- 不要所有元素同时 fade-in
- 最多 3 个元素同时入场

## 基础 timeline

- 所有 clip 都有 fade + slide 转场（y: 40→0 滑入，y: 0→-20 滑出）
- AI 动画与基础叠加（additive）
- 不破坏基础 timeline（不要 tl.kill()）
- 选择器：用 `#stage .clip-{id} > 子元素`

## 反模式

- ❌ 时长 > 500ms
- ❌ linear 缓动
- ❌ 旋转/翻转/弹跳（炫技）
- ❌ 同时 > 3 个元素入场
- ❌ 装饰性动画（纯旋转、无意义晃动）
- ❌ 每个元素都动
