# 逐拍骨架：每幕的功能位置

> 结构纪律给了段落级时间轴，本文档拆到**每一幕的写作任务**。拍数按场景数 ±2 弹性，但每个功能位置必须有人接。分镜时按表填空。

标记：★ = 全片强调位（金句或关键数字，合计 4-6 处，时长自动加长）。

以 12 幕基准（对应 40-60 秒），按实际场景数等比增删：

## 一、钩子（第 1-2 幕）

| 拍 | 功能 | 写法要点 |
|---|---|---|
| b01 | 处境 | 观众亲身经历过的一个具体时刻，前半句切入，不解释 |
| b02 | 疑问 | "是 A（常识答案），还是 B（真相方向）？"或同一件事的反面结果 |

## 二、真实故事：埋悬念（第 2-4 幕）

| 拍 | 功能 | 写法要点 |
|---|---|---|
| b03 | 时间地点 | "年代，地点。"或具体情境 |
| b04 | 抛出现象 | 一句话把问题/实验/现象讲清 |
| b05 | 关键提问 | 把观众心里的问题问出口（"要不要……？"） |
| b06 | 反直觉的答案 | 意外答案（必须查证过） |
| b07 ★ | 悬念金句 | 一句话推翻，**不解释**（解释留给机制段） |

## 三、机制演示：多层反转（第 5-9 幕）

全片最长段落，读数/演示在跑，反转叠在结果上：

| 拍 | 功能 | 写法要点 |
|---|---|---|
| b08 | 设定 | 模型规模与前提 |
| b09 | 规则 | 一条公式式规则 + 一条"哪个变、哪个不变" |
| b10 | 第一组结果 | 强调色高亮，先留悬念（破折号收尾） |
| b11 ★ | 对照数字 | 另一组的结果，只说结果 |
| b12 | 机制解释 | 大白话讲清为什么 |
| b13 ★ | 第一层金句 | 对仗短句，点破第一层 |
| b14 | 第二层反转引子 | 固定句式："更反直觉的是：……" |
| b15 ★ | 第二层金句 | 一句话点破本质（"关键不是 X，是 Y"） |

## 四、解开悬念（第 10 幕）

| 拍 | 功能 | 写法要点 |
|---|---|---|
| b16 | 回到开头 | 固定句式："现在，回到 [开头的那个东西]。" |
| b17 ★ | 揭晓金句 | 两句对仗，解释开头的一切 |

## 五、落到观众与结尾（第 11-12 幕）

| 拍 | 功能 | 写法要点 |
|---|---|---|
| b18 | 清单引子 | "所以，下次遇到这几种时刻——" |
| b19 | 小行动 | "① 场景：建议"格式，冒号前是强调词；最好有一条呼应 b02 |
| b20 ★ | 结尾金句 | 替观众开脱或重新解读，呼应 b01-b02；这是主题的回声 |

## 六、五条硬规矩

1. 每拍 ≤ 30 字，读出来像说话，不像论文。
2. 能用数字就用数字，数字必须先算出或查证，再回填。
3. 金句的前一拍通常是问句或停顿——先造停顿，金句才立得住。
4. 不说教：写"下次……时，想想……"，不写"我们应该……"。
5. 原话、年份、人名，没查证就不写。

## 七、自查三件事

分镜写完只看三点：**悬念埋在二节、解在四节；反转 ≥ 两层；末拍呼应钩子。**
加上强调位不超过 6 处、每个功能位置都有接手，骨架就立住了。
