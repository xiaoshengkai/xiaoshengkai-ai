# 极简黑白
- 纯白底色 #FFFFFF，纯黑文字 #000000，对比度 ≥ 15:1
- 灰色 (#999 ~ #CCC) 仅用于 1px 分割线/边框/几何点缀，禁止灰色文字
- 杂志式非对称排版：左对齐或右对齐，绝不居中
- 标题 粗衬线体（Didot/Bodoni），正文 细无衬线体，字号对比 48px+/16px/10px
- 留白 ≥ 40%，单屏文字 ≤ 3 行
- 动效：仅淡入淡出 + 上下微位移(≤30px)，ease-in-out 0.6-0.8s，无弹跳/旋转
- 装饰：1px 黑色细线 + 几何图形（圆形/方形边框），无图标/emoji/渐变/阴影
- 转场：淡入淡出 0.5s，无彩色 wipe
- 1080×1920 竖屏，面向抖音
- SVG 图表使用实际 hex 色值，不使用 CSS 变量
