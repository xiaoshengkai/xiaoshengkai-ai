你的房贷利率到底谁说了算？

#LPR#房贷利率#基准利率#小白金融

写完代码，点完最后一个分号，打开银行APP一看：房贷利率又没变。不是说降息了吗？为什么月供还是一毛不少？忽然想起——房贷利率跟LPR走，不是跟新闻里的降息。新闻降的是基准利率，央行的指导价，可咱们房贷合同上写的，根本不是它。

出厂价 vs 零售价 vs 你的价

打个比方：基准利率就像手机代工厂的出厂价，普通人根本拿不到。LPR是18家银行每月20号各自报价，去掉最高最低取平均，相当于市场批发价。加点呢？根据你首套还是二套、征信好不好、政策松紧，一次性定死，签约后永远不变。

房贷 = LPR（每月可能变）+ 加点（签合同时焊死）

那18家报价行：6家国有大行 + 5家股份制 + 5家股份制 + 北京上海城商行 + 渣打/微众。这帮大佬每月一开会，月供涨跌就看他们喊价。

银行怎么赚钱？——靠你的存款

很多人以为银行是从央行借钱再放贷。真相：银行主要靠你的存款赚钱。你的存款占银行资金来源的70%，银行给你1.3%的利息，转手以3.8%贷出去——净赚2.5%的利差。这就是为什么降息时存款利息降得比房贷快，银行要保住自己的蛋糕。

三个角色，一张表看清

角色对应什么变不变
基准利率央行定的出厂价几乎不动
LPR18家银行报价的批发价每月20号更新
加点你签合同时锁死的溢价永远不变
你的房贷 = LPR + 加点。LPR降你就少还，加点定了就认命。

算一笔账

贷款100万，LPR降0.25% → 月供少约150块 → 一年省1800，够带老婆吃顿好的。

但如果加点被定高了——别人加30个基点，你征信差加60个基点——每年多还3000多，三十年就是多还近10万。这10万块，跟你签合同时那支笔有直接关系。

盯着新闻里的降息没用。你要盯的是每月20号的LPR，还要记住合同里的加点。征信好加点低，征信差加点高——签合同的那一刻就焊死了。
